Cortes

Cortes is a personal desktop tool that helps a streamer or an authorized editor cut highlights from live streams (with the streamer's permission), prepare a caption with hashtags, and, only when the user chooses, send the finished video to the user's own TikTok account through TikTok's Content Posting API.

Every upload is reviewed and explicitly confirmed by the user before anything is sent to TikTok. The app never posts on its own.

  • Runs on the user's own computer; there is no Cortes server.
  • Uses TikTok Login Kit to connect the user's own account.
  • Uses the Content Posting API to upload a video the user has approved.
